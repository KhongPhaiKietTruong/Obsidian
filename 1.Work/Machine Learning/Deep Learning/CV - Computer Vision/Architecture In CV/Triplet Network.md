## Định Nghĩa 
Triplet Network là một kiến trúc mạng thuộc [[Self-Supervised Learning]] học dựa trên các mẫu được ghép từ 3 thành phần khác nhau: Anchor, Postive, Negative 

## Loss Function
Triplet Net sử dụng [[Triplet Loss]] 

## Công Dụng 
triplet network thường được sử dụng trong các tác vụ:
- Face Recognition 
- Image Retrievial 
- Person Re-identification
