Kí hiệu: $J( y, \hat{y})$
Dịch: Hàm Mất Mát

## Định Nghĩa 
Loss function là một hàm số cho ta biết rằng giá trị mà model dự đoán ra có độ lệch là bao nhiêu so [[Ground Truth]], nếu độ lệch lớn, [[Penalty]] phạt model sẽ cao, bắt model phải cố học để giá trị dự đoán của nó sát với ground truth 

## Các Loại Loss 
Có nhiều loại loss function khác nhau giành cho các vụ khác nhau, chủ yếu là gồm 2 loại chính:
- regression (dựa trên độ lệch giá trị)
- classification (dựa trên xác suất)
