mỗi ô chính là đại diện cho một class
mỗi ô gồm 3 thành phần chính: tên class, [[Attribute]], [[Method]] 
với các biểu tượng sử dụng:
Symbols used:

| Symbol   | Meaning                   |
| -------- | ------------------------- |
| `+`      | Public                    |
| `-`      | Private                   |
| `#`      | Protected                 |
| `: void` | Method returns nothing    |
| `: int`  | Method returns an integer |
