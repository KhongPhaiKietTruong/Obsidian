## Định Nghĩa 
MVVM là một [[Architecture Pattern]] chia code thành 3 thành phần 
- View: giao diện người dùng
- ViewModel: xử lí các thao tác người dùng 
- Model: lưu trữ, xử lí dữ liệu (trong model còn chia nhỏ thành repository và datasource)
