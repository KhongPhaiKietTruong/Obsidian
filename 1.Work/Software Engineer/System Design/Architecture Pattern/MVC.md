## Định Nghĩa 
MVC là một [[Architecture Pattern]] tổ chức code thành 3 thành phần chính:
- Model: quản lí dữ liệu 
- View: hiển thị dữ liệu lên giao diện người dùng 
- Controller : nhận vào các thao tác của người dùng và điều phối quá trình xử lí giữa View và Model
