## Định Nghĩa 
Container là một môi trường độc lập gồm các thư viện, thiết lập, ... do ta chỉ định 

## So Sánh Với Máy Ảo 
Container cũng gần tương tự như [[VM - Virtual Machine]], tuy nhiên container nhanh và nhẹ hơn rất nhiều vì nó dùng chung kernel của hệ điều hành, hay nói cách khác, mỗi container là một user space, còn mỗi máy ảo là một hệ điều hành hoàn chỉnh
