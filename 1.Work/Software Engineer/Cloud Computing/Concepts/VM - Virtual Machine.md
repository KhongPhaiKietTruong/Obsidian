## Định Nghĩa 
VM là một môi trường điện toán được giả lập bằng phần mềm, hoạt động như một máy tính riêng biệt bao gồm hệ điều hành, CPU, RAM, ... được quản lí bởi [[VMM - Hypervisor]] 

## So Sánh Với Container
Máy ảo khác với container ở chỗ, mỗi máy ảo là một hệ điều hành riêng biệt, còn mỗi container là các user space dùng chung một kernel của một hệ điều hành
