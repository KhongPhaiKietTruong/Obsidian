## Định Nghĩa 
MCP Server là nơi cung cấp cho AI các khả năng, giúp AI có thể truy cập dữ liệu, sử dụng công cụ và tương tác với hệ thống bên ngoài 

## Thành Phần 
Bên trong MCP Server gồm có:
- Tools: các tools (read_file(), search_github(), ...)
- Resources: dữ liệu (các table trong PostgreSQL)
- Prompts: các template mẫu hướng dẫn AI làm việc   

## Nơi triển khai MCP Server
MCP server có thể được chạy local hoạt remote
