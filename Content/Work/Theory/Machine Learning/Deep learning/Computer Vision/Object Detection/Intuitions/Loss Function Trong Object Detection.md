ta có thể [[SE (Squared Error)]] cho mọi giá trị
$$
L(\hat{y},y)
=
(\hat{p}_c-p_c)^2
+
p_c
\left[
(\hat{b}_x-b_x)^2
+
(\hat{b}_y-b_y)^2
+
(\hat{b}_h-b_h)^2
+
(\hat{b}_w-b_w)^2
+
\sum_{i=1}^{3}(\hat{c}_i-c_i)^2
\right]
$$
