$$
y = w_{1}x_{1} + w_{2}x_{2} + \dots + w_{n}x_{n} + b
$$

$$y = w_1x_1 + w_2x_2 + w_3x_1^2 + w_4x_1x_2 + w_5x_2^2 + b$$
