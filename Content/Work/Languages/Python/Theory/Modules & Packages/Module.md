module là một file python chứa các [[Variables (Biến)]], [[Function (Hàm)]], [[Class (Lớp)]], ...

ở một file python khác ta sẽ import một module và sử dụng các thứ có trong module đó 

module giúp chúng ta tổ chức code một cách tường minh hơn và tăng tính tái sử dụng code, giúp chúng ta không cần phải ghi tất cả mọi thứ chỉ trong một file python
