viết tắt của: Squared Error Loss 
dịch: trung bình sai số bình phương
tên khác: L2 Loss 

thường được dùng trong bài toán hồi quy, có công thức:
$$SE = (y_i - \hat{y}_i)^2$$
- $n$: Tổng số mẫu dữ liệu.
- $y_i$: [[Ground Truth]]
- $\hat{y}_i$: [[Predicted Value]] từ mô hình.
- $(y_i - \hat{y}_i)$: Sai số của từng mẫu.

đây thường là lựa chọn default
