viết tắt của: Absolute Error Loss
dịch: Squared Error (sai số tuyệt đối)
tên khác: L1 loss

AE loss có công thức:
$$AE = |(y_i - \hat{y}_i)|$$
với: 
- $n$: Tổng số mẫu dữ liệu trong [[Training Set]].
- $y_i$: [[Ground Truth]]
- $\hat{y}_i$: [[Predicted Value]] từ mô hình.
- $(y_i - \hat{y}_i)$: Sai số của từng mẫu.
