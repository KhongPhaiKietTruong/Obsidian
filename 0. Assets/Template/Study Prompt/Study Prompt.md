I want to learn .

Explain it in a clear, intuitive, and structured way. Assume I am learning this topic for the first time, but I already have some background knowledge in related areas.

Please explain it in the following order:

1. **Simple explanation**
    - What is ?
    - Explain it first in very simple language.
    - Avoid unnecessary jargon.
    - If technical terms are necessary, define them immediately.
    - Give an intuitive analogy if it helps.
2. **The problem it solves**
    - What problem existed before ?
    - Why was created or introduced?
    - What limitation of previous methods does it address?
    - Give a concrete example showing the problem.
3. **Core idea / intuition**
    - What is the main idea behind ?
    - Explain the mechanism conceptually before introducing formulas or implementation details.
    - Walk through a small example step by step.
4. **How it works**
    - Explain the important components and the process from input to output.
    - If there are several steps, explain them in the correct order.
    - Clearly distinguish concepts that are commonly confused with each other.
5. **Mathematical explanation**
    - If the topic involves mathematics, introduce the relevant formulas only after explaining the intuition.
    - Explain the meaning of every variable and symbol.
    - Connect each part of the formula to the intuition explained earlier.
    - Include a small numerical example if useful.
6. **When it is used**
    - In what situations is useful?
    - What kinds of problems commonly use it?
    - Give several realistic examples.
    - Also explain situations where using it would be unnecessary or inappropriate.
7. **Advantages**
    - What are the main advantages of ?
    - Explain why each advantage matters in practice.
8. **Disadvantages and limitations**
    - What are its weaknesses?
    - What assumptions does it make?
    - What situations make it perform poorly?
    - What common problems can occur when using it?
9. **Comparison with related concepts**
    - Compare with the most similar or commonly confused concepts.
    - Explain the important differences in intuition, purpose, and use cases.
    - Do not just list definitions.
10. **Connection to my existing knowledge**
    - Explain how connects to concepts I may already know.
    - Show prerequisite → → later concepts.
    - Explain whether is:
        - a concept,
        - technique,
        - algorithm,
        - model,
        - architecture,
        - component,
        - mathematical function,
        - evaluation metric,
        - or something else.
    - Clearly state where it belongs in the larger knowledge hierarchy.

    Show a small hierarchy such as:
    broader topic  
    → related concept

    → techniques/models that use it  
    → more advanced concepts

2. **Common misconceptions**  
    List common misunderstandings beginners have about and correct them.
3. **What I should remember**  
    Summarize the topic into 3–5 essential points that are worth memorizing.
4. **Check my understanding**

While explaining:

- Start with intuition, then details, then mathematics.
- Prefer concrete examples over abstract definitions.
- Explain cause-and-effect: not only what happens, but why.
- Connect new ideas to previously learned concepts whenever possible.
- If a concept depends on prerequisites I may not know, briefly explain those prerequisites first.
- Mention the English terminology for important concepts.
- Use formulas when they genuinely improve understanding, not just for formality.
- For machine learning / deep learning topics, explain tensor or matrix dimensions when relevant.
- If there are multiple ways to interpret a term, distinguish them explicitly.
- Point out what is essential for understanding versus what can be learned later.
